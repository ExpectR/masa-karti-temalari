Cloudflare FLUX.1 Schnell bağlantısı. Anahtar yalnızca bu Windows hesabında açılabilen şifreli bir dosyada tutulur.

Atölyedeki FLUX → Bağlantı bölümüne bu kodu yapıştır. Bu kod API anahtarı değildir.

Ücretsiz Workers planını kullan. Ücretli plan otomatik açılmaz. Bilgisayarı yeniden başlatınca FLUX Başlat.cmd dosyasını aç.
